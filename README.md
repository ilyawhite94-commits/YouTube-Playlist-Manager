# YouTube Playlist Manager (Папки для плейлистов YouTube)

Группируйте плейлисты YouTube по папкам, как файлы на компьютере: по темам и интересам.

## Возможности

- **Плейлисты.** Дерево папок с вложенными подпапками, перетаскивание, по четыре превью у каждого плейлиста. Клик по плейлисту открывает список его видео с превью прямо в окне.
- **Подписки.** Каналы тоже раскладываются по папкам. Можно включить фильтр ленты подписок: на странице «Подписки» останутся видео только из выбранной папки.
- **Окно «Сохранить в плейлист».** Над списком плейлистов под видео появляются кнопки с вашими папками, и список фильтруется по ним.
- **Заметки.** К любому видео можно добавить заметку и метки, вставлять метки времени вида `[12:34]` (они становятся ссылками) и искать по заметкам.
- Поиск, тёмная и светлая темы YouTube. Кнопка «Папки» появляется при наведении мыши на правый нижний угол любой страницы и скрыта в полноэкранном и широкоформатном режимах.

## Установка

### Вариант 1. Tampermonkey (рекомендуется)

1. Установите [Tampermonkey](https://www.tampermonkey.net/). В новых версиях Chrome может понадобиться один раз включить «Разрешить пользовательские скрипты» в настройках расширения.
2. Откройте [ytpf.user.js](https://github.com/ilyawhite94-commits/YouTube-Playlist-Manager/raw/main/ytpf.user.js) и нажмите «Установить».

Обновления приходят автоматически.

### Вариант 2. Расширение для браузера (Chrome, Edge, Brave, Opera)

1. Нажмите **Code → Download ZIP** и распакуйте архив в постоянную папку (потом её не удаляйте).
2. Откройте `chrome://extensions` (в Edge `edge://extensions`) и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите распакованную папку.

Не включайте оба варианта сразу: у них раздельные данные и будет две кнопки.

## Как пользоваться

1. Откройте `youtube.com/feed/playlists` и прокрутите страницу вниз, чтобы YouTube подгрузил все плейлисты. Они появятся в разделе «Без папки». Подписки загружаются кнопкой «Обновить подписки» на вкладке «Подписки».
2. Наведите мышь на правый нижний угол страницы и нажмите «Папки».
3. Создайте папки слева и перетащите в них плейлисты. Клик по плейлисту открывает список видео.

## Приватность

Папки и список плейлистов хранятся только в вашем браузере. Скрипт обращается только к youtube.com и i.ytimg.com (превью) и никуда ничего не отправляет.

## Ограничения

- YouTube часто меняет вёрстку, поэтому после обновлений сайта что-то может перестать работать. Напишите об этом в [Issues](https://github.com/ilyawhite94-commits/YouTube-Playlist-Manager/issues).
- Синхронизации между устройствами нет.
- Закрытые плейлисты открываются, только если вы вошли в свой аккаунт.
