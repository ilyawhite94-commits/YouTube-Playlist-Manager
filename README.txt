Папки для плейлистов YouTube: установка (Chrome, Edge, Brave, Opera)

1. Распакуйте архив в постоянное место, например в Документы. После установки
   папку не удаляйте и не переносите: браузер читает расширение прямо из неё.
2. Откройте страницу chrome://extensions (в Edge: edge://extensions)
   и включите «Режим разработчика» в правом верхнем углу.
3. Нажмите «Загрузить распакованное расширение» и выберите папку ytpf-extension.
4. Откройте youtube.com/feed/playlists и прокрутите страницу вниз:
   плейлисты подхватятся сами.
5. Кнопка «Папки» появляется, когда вы наводите мышь на правый нижний угол
   любой страницы YouTube.

Папки и плейлисты хранятся только в вашем браузере и никуда не отправляются.
Если после обновления YouTube что-то перестало работать, напишите автору.
